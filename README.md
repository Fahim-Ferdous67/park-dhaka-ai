
# ParkDhaka AI 🅿️
**Solving Dhaka's parking crisis with predictive AI and live B2B synchronization.**

ParkDhaka is a two-sided marketplace designed to reduce urban gridlock by connecting drivers to underutilized commercial parking spaces. Using Google Gemini AI, the platform predicts lot occupancy trends, allowing drivers to book spots before they even arrive.

## 🚀 Core Features
* **Predictive AI Insights:** Uses Gemini AI to analyze historical data and predict lot availability.
* **Live B2B Dashboard:** A dedicated interface for lot managers to handle entries and bookings in real-time.
* **Zero-Hardware Integration:** No expensive sensors needed; powered entirely by smart software and logic.
* **Smart Mapping:** Interactive Dhaka map for easy navigation to secured spots.

## 🛠️ Tech Stack
* **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+)
* **Backend/Automation:** Make.com (Webhooks & Logic)
* **AI Engine:** Google Gemini AI
* **Database:** Google Sheets (via Live CSV Sync)
* **Hosting:** GitHub Pages
